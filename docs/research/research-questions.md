# Research Questions

Initial research questions LucidUI is designed to eventually help answer. These require dataset-level experiments (multiple screenshots, multiple raters) — no single screenshot analysis can answer them. See [evaluation-plan.md](evaluation-plan.md) for how these would be studied and [docs/product/non-goals.md](../product/non-goals.md) for the explicit boundary against drawing conclusions from one screenshot.

1. To what extent do deterministic UI metrics (LucidUI) and UIClip produce similar evaluation signals?
2. In which UI categories (dashboards, landing pages, forms, e-commerce, mobile) do LucidUI and UIClip diverge most?
3. Which deterministic metrics are most associated with human ratings of UI quality/usability?
4. How does UIClip's preference score compare with human ratings?
5. Does showing explanations (deterministic metric evidence) improve user understanding or trust relative to a single opaque score?
6. Does combining deterministic signals and a learned evaluator provide more useful feedback than either alone?

## Status

These are open research questions, not established findings. None of them have been answered yet — no dataset-level experiment has been run as of Phase 0. See [experiment-log.md](experiment-log.md) for the template that will record actual experiment results once they exist, and [ROADMAP.md](../../ROADMAP.md) Phase 10 for when benchmarking work is scheduled.
