# Experiment Log

A reusable template for recording LucidUI research experiments. Copy the template below for each new experiment entry. No experiments have been run as of Phase 0 — this file intentionally contains no results yet. See [evaluation-plan.md](evaluation-plan.md) and [research-questions.md](research-questions.md) for the context experiments should draw on.

## Template

```markdown
### Experiment ID: EXP-XXXX

- **Date**: YYYY-MM-DD
- **Research question**: Which question from research-questions.md this addresses.
- **Dataset**: Name/location, size, UI categories covered.
- **Model versions**: UIClip checkpoint/version used.
- **Metric-engine version**: LucidUI engine version and scoring-ruleset version used.
- **Configuration**: Context mode, weights, thresholds, any non-default settings.
- **Hypothesis**: What is expected before running the experiment.
- **Procedure**: Steps taken to run the experiment.
- **Results**: Raw findings — numbers, tables, or links to output files.
- **Problems**: Any issues encountered (data quality, failures, anomalies).
- **Interpretation**: What the results mean, with appropriate hedging and caveats from known-limitations.md.
- **Next action**: Follow-up experiment, fix, or decision resulting from this entry.
```
